ถ้าการทดสอบไม่ผ่าน

  1. ตรวจว่า URL ลงท้ายด้วย /exec ไม่ใช่ /dev
  2. ตรวจว่าตอน Deploy เลือก Who has access = Anyone
  3. เปิด URL นั้นในแท็บใหม่โดยตรง ถ้าเห็นข้อความ JSON แปลว่าเซิร์ฟเวอร์ทำงาน ปัญหาอยู่ที่ CORS
  4. ถ้าขึ้นหน้าขอให้ลงชื่อเข้าใช้ Google แปลว่าตั้งค่าสิทธิ์การเข้าถึงผิด
  5. ส่งภาพหน้าจอของหน้านี้ทั้งหน้ากลับมา
